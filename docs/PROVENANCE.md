## Turnip / Adreno 660 decision

Turnip is Mesa's Vulkan driver for Adreno 6xx GPUs. The Adreno 660 is in the Adreno 6xx family, but that alone does not establish that a specific community build is compatible with this device's kernel, KGSL, Android/HarmonyOS image, Vulkan WSI, or memory/gralloc path. The release must pin a Mesa commit and build recipe, ship `libvulkan_freedreno.so`, `meta.json`, required license texts, and corresponding source/patches.

## Critical loader boundary

`libadrenotools` loads a custom Android/Bionic Vulkan driver into the Android app process by hooking Android's Vulkan loader. Wine/Box64 under the Debian glibc rootfs is a separate guest userspace. Loading Turnip into the Android process does **not** automatically make that driver loadable by a glibc process. The project still needs a proven glibc-visible Vulkan loader/ICD and a WSI/presentation bridge that reaches the Android surface. Do not describe the adrenotools hook as a completed Wine Vulkan bridge.

## Redistribution checklist

- [ ] Pin exact source commits and release tags for every component.
- [ ] Record SHA-256 for every shipped binary/archive.
- [ ] Include component license texts and upstream notices.
- [ ] Include corresponding source or a compliant written source offer for GPL/LGPL components where required.
- [ ] Preserve Debian `/usr/share/doc/*/copyright` data or equivalent license manifest.
- [ ] Review all transitive native-library licenses before embedding them in the APK.
- [ ] Do not include proprietary game binaries, Unity Player files, or user game assets.
