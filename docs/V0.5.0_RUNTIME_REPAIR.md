# Ghost Town Recomp v0.5.0-alpha.1 — Bundled Runtime Repair

## Changes
- Runtime extraction handles repeated hardlink entries without failing when the same inode link has already been created.
- Conflicting archive entries follow safe tar replacement behavior for non-directory destinations.
- Absolute symbolic links are accepted only when their normalized target remains inside the private staging directory; they are rewritten as relative links before creation.
- Symbolic links that escape the staging root remain rejected.
- First launch provisions the runtime shipped in the APK.
- The dashboard no longer asks users to browse for a runtime archive or download a separate runtime package.
- A single **Install / Repair Built-in Runtime** action retries extraction from the APK asset.

## Validation status
This release must still pass GitHub Actions build, lint, and probe tests. Successful APK packaging does not prove runtime execution on a physical device.

## Known limitations
- Wine/Box64 game execution, Vulkan presentation/Turnip integration, audio and input bridges, and Overcooked! 2 gameplay remain experimental and are not certified by this runtime installer change.
- Users must provide their own legally obtained Overcooked! 2 PC game files. No proprietary game binaries are bundled.
- Physical Huawei MatePad Air 2023 validation is still required.
